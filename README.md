# Aarya — Marathi-first personal AI companion

Aarya is a mobile-first AI assistant for Marathi and English speakers. It supports
general conversation, emotional support, study help, planning, career, translation,
tech, travel, and a source-aware government-schemes section. Marathi is the default
language.

## Features
- Chat with Marathi/English toggle
- Voice read-aloud of answers (expo-speech)
- Microphone button (STT integration pending — shows "unavailable" state honestly)
- Loading, error, retry, clear-chat, offline fallback
- Government schemes list + preliminary eligibility wizard
- Persistent disclaimers in both languages
- All AI keys stay server-side
